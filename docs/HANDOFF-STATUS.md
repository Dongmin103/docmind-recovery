# 인수인계 상태

날짜: 2026-09-21

## 포함

- 변경 전 DocMind/RAGFlow 커스텀 소스: Python, web, Go, 파서 sidecar, 빌드 파일·lockfile·라이선스·기존 테스트 코드.
- 최신 PRD v0.17 및 구조/개발/제거 조사 문서.
- 일반 코드 테스트용 합성 fixture, 파서 tokenizer 자원 및 UI 이미지/폰트. 운영 문서·검색 결과가 아니다.
- Windows 읽기 전용 사전 점검과 새 로그인용 RSA 키 준비 도구.

## 제외

- 원본 PDF/Office/HWP 문서, 운영 청크·벡터·DB·MinIO 객체·OpenViking 카탈로그.
- 기존 .env/서버 설정, 실제 개인키, 복호화/백업 키, SSH 자격증명, 컨테이너 환경 덤프.
- 원본 Git bundle/history, 기존 Docker 이미지, 모델 가중치, 실행 중인 프로세스 상태.
- 임시 출력/비정상 파일명 산출물, 이전 canary 설정 사본 및 옛 release metadata.

기존 복구 릴리스는 별도로 보존하며 이 개발 브랜치에 재업로드하거나 내려받을 필요가 없다. 이 브랜치는 전체 운영 환경을 복원하는 묶음이 아니다.

## 공개 준비를 위한 소스 차이

- 실제 환경설정은 제외하고 기본 템플릿을 남겼다. 템플릿에서 기존 설정 값과 일치한 일부 값은 새 개발 값 입력 표시로 바꿨다. system_settings의 외부 연동 값은 비웠다.
- 예제 curl의 리터럴 인증 헤더는 환경변수 입력으로 바꿨다. 통합 테스트의 기존 암호화 비밀번호도 서버에서 새로 제공한다.
- Windows checkout에서 심볼릭 링크 권한이 없어도 문서를 읽도록 CLAUDE.md를 AGENTS.md 내용으로 구체화했다. PDF 도구 테스트의 상대 testdata 링크도 일반 파일로 구체화했다.
- 기존 개인키를 제외했으므로 새 개발 키와 프런트 공개키 갱신이 필요하다. initialize_auth_keys.py가 이를 처리한다.
- 새 PRD의 기능 리팩터링, 실제 데이터 이관, 서비스 배포는 이 작업에서 수행하지 않았다.

## 검증 한계

공개 전 파일 제외·비밀정보·소스 문법·인수인계 도구와 Git clone 무결성을 확인한다. 실행 환경은 다른 장비이므로 Windows Docker 전체 기동, uEncryptor2, 클라우드 API, 실제 Jina 호출과 성능은 서버에서 검증할 후속 작업이다. 세부 검사 수치는 HANDOFF-VERIFICATION.json을 따른다.
