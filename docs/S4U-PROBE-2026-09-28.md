# Same-user S4U capability probe

The current DocMind tasks run as `uplex` with an `Interactive` principal. A
same-user `S4U` task is the least disruptive candidate for running after
logout, but this host has not proved that WSL and the local source roots work
under that token. An unelevated attempt to register a temporary S4U task
returned Windows `Access is denied`; no task or report was created. This is a
Windows permission failure, separate from the earlier automatic command-review
rejection.

Run the following in an **elevated PowerShell session as `uplex`** when the
operator is ready to test. It registers a one-off task with a future trigger,
starts it manually, reads boolean-only results, then removes the task and its
report. It does not decrypt or scan source files, read the shared secret, change
an existing task, or enable a source. The probe script only lists at most one
top-level entry in each configured source root.

```powershell
$repo = 'C:\DocMindDev\docmind'
$config = Join-Path $repo '.local\uEncryptor2\host-worker.live.json'
$report = Join-Path $repo '.local\uEncryptor2\s4u-probe-result.json'
$probe = Join-Path $repo 'tools\windows\Test-DocMindS4UContext.ps1'
$taskName = 'DocMind S4U Probe Temporary'
$identity = [Security.Principal.WindowsIdentity]::GetCurrent()
if ($identity.Name -ne "$env:COMPUTERNAME\uplex") { throw 'Run elevated as uplex.' }
if (Get-ScheduledTask -TaskName $taskName -ErrorAction SilentlyContinue) {
    throw 'Temporary probe task already exists.'
}
if (Test-Path -LiteralPath $report) { throw 'Old probe report already exists.' }
$registered = $false
try {
    $principal = New-ScheduledTaskPrincipal -UserId $identity.Name -LogonType S4U -RunLevel Limited
    $shell = Join-Path $env:SystemRoot 'System32\WindowsPowerShell\v1.0\powershell.exe'
    $arguments = '-NoProfile -NonInteractive -WindowStyle Hidden -ExecutionPolicy RemoteSigned -File "{0}" -ConfigPath "{1}" -ExpectedUserSid "{2}" -OutputPath "{3}"' -f $probe, $config, $identity.User.Value, $report
    $action = New-ScheduledTaskAction -Execute $shell -Argument $arguments -WorkingDirectory $repo
    $trigger = New-ScheduledTaskTrigger -Once -At ((Get-Date).AddHours(1))
    $settings = New-ScheduledTaskSettingsSet -ExecutionTimeLimit (New-TimeSpan -Minutes 2)
    Register-ScheduledTask -TaskName $taskName -Action $action -Trigger $trigger -Settings $settings -Principal $principal -ErrorAction Stop | Out-Null
    $registered = $true
    Start-ScheduledTask -TaskName $taskName -ErrorAction Stop
    for ($attempt = 0; $attempt -lt 45; $attempt++) {
        $task = Get-ScheduledTask -TaskName $taskName
        if ($task.State -ne 'Running' -and (Test-Path -LiteralPath $report)) { break }
        Start-Sleep -Seconds 2
    }
    if ((Get-ScheduledTask -TaskName $taskName).State -eq 'Running' -or
        -not (Test-Path -LiteralPath $report)) {
        throw 'Probe did not finish with a report within 90 seconds.'
    }
    Get-ScheduledTaskInfo -TaskName $taskName | Select-Object LastTaskResult
    Get-Content -LiteralPath $report -Raw | ConvertFrom-Json | Format-List
} finally {
    if ($registered) {
        $task = Get-ScheduledTask -TaskName $taskName -ErrorAction SilentlyContinue
        if ($task -and $task.State -eq 'Running') {
            Stop-ScheduledTask -TaskName $taskName -ErrorAction SilentlyContinue
        }
        Unregister-ScheduledTask -TaskName $taskName -Confirm:$false -ErrorAction SilentlyContinue
    }
    if (Test-Path -LiteralPath $report) { Remove-Item -LiteralPath $report }
}
```

All seven results should be `true` before considering a same-user S4U task
migration. A successful probe while `uplex` is logged in establishes the token's
local access and WSL launch ability only. Actual logout and reboot recovery
still require separate tests after the active job count and plaintext residue
are zero. If the S4U probe fails, leave the current tasks unchanged and inspect
Task Scheduler's last result and operational event log; do not switch to
`SYSTEM` or another Windows user merely to make registration succeed. WSL
distributions are registered per Windows user, and the current `Ubuntu`
distribution belongs to `uplex`.
