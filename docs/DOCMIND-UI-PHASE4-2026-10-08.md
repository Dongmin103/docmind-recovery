# DocMind UI 4차 작업 기록 — 2026-10-08

**후속 요청으로 원복:** 사용자는 자료관리는 기존 화면으로 유지하고 검색 범위의 폴더 선택 부분만 개선하려던 의도임을 명확히 했다. 아래는 당시 작업 기록이며, 자료관리 UI와 관련 테스트·스타일은 `ed6cf64` 상태로 되돌렸다. All-in-One 신규 연결은 현재 작업 범위에서 제외하고 기존 안내를 유지한다.

기준 커밋: `ed6cf64`. 검토 서버: <http://127.0.0.1:18081/docmind>.

## 적용 범위

- 자료관리 제목과 새로고침을 같은 상단 영역에 두고, 문서 라이브러리를 주 영역으로 넓혔다. 처리 현황은 데스크톱의 보조 영역, 좁은 화면에서는 목록 아래에 배치한다.
- 문서 목록의 중첩 카드를 제거하고 폴더/파일 아이콘과 계층선을 사용한다. 상위 두 단계는 처음부터 펼치고, 사용자가 접거나 펼친 상태는 목록 갱신에도 유지한다.
- 긴 폴더·문서 이름과 상태·액션은 줄바꿈한다. 깊은 계층의 들여쓰기는 제한하고 실제 단계 수를 표시한다.
- 실제 처리 상태를 작은 배지와 구분선으로 정리했다. 기존 원문 이동, OCR 선택, 등록 기록 필터, 재시도 권한과 경고는 유지한다.
- 처리 현황을 가져오는 중에 빈 목록 문구가 먼저 나타나던 문제를 수정했다. 로딩·실패·빈 상태를 구분한다.
- 업로드는 기존 `can_upload` 조건 그대로이며 새 업로드/삭제 기능은 추가하지 않았다.

All-in-One 이동 주소는 코드·문서에서 확인되지 않았다. 사용자에게 실제 URL/실행 경로를 요청했으며, 답변 전에는 기존 안내를 유지한다. 주소나 실행 수단을 임의로 만들지 않는다. 이 항목은 당시 미완료였으며 후속 요청으로 현재 작업 범위에서 제외되었다.
