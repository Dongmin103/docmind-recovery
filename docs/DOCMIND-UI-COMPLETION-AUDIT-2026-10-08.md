## 최종 점검에서 수정한 누락

`/user-setting/data-source/data-source-detail-page`가 `/user-setting`의 자식이 아닌 별도 route여서 기존 부모 loader를 거치지 않았다. 해당 route에 같은 리디렉션 loader를 적용하고, 알려지지 않은 설정 하위 주소도 부모 guard를 거치도록 wildcard 자식을 추가했다. 테스트는 부모 loader만 직접 호출하던 방식에서 실제 일치하는 route branch를 확인하는 방식으로 변경했다. 백엔드 권한이나 설정 API는 변경하지 않는다. 최종 브라우저에서 10개 설정 주소를 360/1440px로 각각 열어 20/20 리디렉션을 확인했다. 설정 UI 노출·페이지/콘솔 오류·변경 요청은 0이며, 검색과 자료관리 접근은 정상이다.
