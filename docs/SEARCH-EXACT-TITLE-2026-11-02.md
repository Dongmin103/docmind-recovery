# 일반 검색: 정확히 일치하는 파일명을 먼저 표시

확장자와 공백을 제외한 전체 파일명이 검색어와 같으면 해당 문서 그룹을 맨 앞에 둔다. 대소문자와 유니코드 표기는 기존처럼 정규화하고, 숫자·기호·파일명 내부의 점은 보존한다. 부분 일치나 파일명 뒤에 질문을 덧붙인 경우에는 우선순위를 주지 않는다. 동명 문서끼리와 나머지 문서끼리는 원래 재평가 순서를 유지한다.

32문서 제한을 적용하기 전에 순서를 정한다. 접근 가능한 검색 범위의 활성 카탈로그에서 정확한 파일명을 찾았는데 일반 후보에 없으면 그 누락 문서로만 범위를 제한해 검색 가능한 청크를 한 번 더 조회한다. 보충 시에도 기존 버전·권한 검증과 전체 128후보 상한을 지킨다. 파일명 일치가 없으면 추가 조회하지 않는다. AI 답변, Jina 입력(청크 앞 2,400자) 및 화면 표시는 변경하지 않았다.

## 이전 배포본과의 비교

비교 기준은 10월 19일 배포한 최대 32문서 이미지다. 해당 서버에서 복사한 이전 결과 선택 코드와 변경 코드에 **동일한 92개 질문의 저장된 후보 및 Jina 점수**를 입력했다. 재현 도구: `tools/compare_docmind_exact_titles.py` (이전 선택 모듈, 비공개 평가 JSON 두 개를 인자로 받음).

| 확인 항목 | 이전 | 변경 후 |
|---|---:|---:|
| 요청한 실제 제목 질문의 정답 순위 | 10위 | 1위 |
| 실제 제목 질문의 지정 정답이 첫 번째 | 4/12 | 12/12 |
| 파일명 완전 일치 후보가 있는 질문에서 일치 문서가 첫 번째 | 13/22 | 22/22 |
| 완전 일치가 없는 질문의 문서·근거·점수·관련성 상태 동일 | 기준 | 70/70 |

배포 전 실제 서버에서 해당 제목 질문의 **102후보·10문서·정답 10위**를 다시 확인했다. 후보 이미지로 실제 검색했을 때 정답은 1위였고, 나머지 문서 순서와 근거가 동일했다. 일반 검색 2건(결과 없음, 6문서 반환)도 실제 서버의 기존 결과와 동일했다. 이 표는 지정한 질문에 대한 결과이며 모든 업무 질의의 정확도 측정은 아니다.

검색·선택·AI 답변 분리 회귀 77개 통과. 신규 테스트는 32문서 제한 밖의 일치, 동일 제목 간 순서, 본문 근거 유지, 부분·기호 불일치, 현재 카탈로그 이름, 범위 밖 문서 제외 및 보충 후 128후보 상한을 확인한다. 이미지의 Python 파일 290개 중 의도한 두 검색 모듈만 바뀌었다.
