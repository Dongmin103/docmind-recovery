# 일반 검색 후보·문서 그룹·관련성 개선

사용자 승인 범위는 기존 조사 항목 4·5·6의 구현, 기존 배포본과 비교, 검증 후 배포다. 항목 3의 청크 본문 앞 2,400자 입력은 유지한다. 청킹·색인·임베딩 모델·C128·Jina v3.5·권한과 활성 버전 조건을 변경하지 않는다.

## 최종 동작

- 유효 검색 범위가 5개 이하 문서이면 문서당 8개 우선 확보 후 남은 RRF 후보를 전체 128개까지 보충한다. 전체 문서 검색처럼 범위가 넓으면 문서당 8개를 유지해 여러 문서에 판단 기회를 준다.
- 일반 검색 결과는 최대 5개 문서다. 문서별 대표 위치 하나와 추가 위치 최대 4개를 묶어 보여준다. 같은 문서에서 공백만 다른 동일 본문은 제거하고, 수치나 사실이 다른 본문은 유지한다. 추가 위치도 해당 청크의 원문 위치를 연다.
- 일반 검색은 Jina의 원래 점수를 사용한다. 원래 구현은 배치에 음수 등이 포함되면 min-max 정규화하여 낮은 관련성의 최고 후보도 1점이 될 수 있었다. 0.25 미만은 제외하고 최고 점수가 0.50 미만이면 낮은 관련성을 안내한다. 남는 결과가 없으면 `no_match`를 반환한다. 점수는 정답 확률이 아니다.
- 전체 파일명 일치는 NFKC·대소문자·확장자·공백을 정규화한 뒤 보호한다. 부분 제목 일치나 `C++`/`C#` 병합은 하지 않는다. 본문만 평가하는 기존 일반 검색의 제목 조회 손실을 막기 위한 예외다.
- AI 답변의 후보 보충, 파일명 포함 입력, 점수 정규화, 최대 16개 근거와 검증 흐름은 유지한다. 추가 위치에도 기존 source 버전·chunk set·권한 검증과 경로 보강을 적용한다.

## 비교 방법과 범위

기준 배포 이미지는 `docmind-ragflow:lexical-candidate-20261019`, ID는 `sha256:81dceae063870f9e29705cad06e573ca057ae807717837b0e5949ade5ed4b5b7`이다. 실제 GTE 임베딩, Elasticsearch의 독립 BM25/dense 검색, RRF, Jina v3.5를 사용했다. 합성 문서는 별도 임시 색인에만 넣었으며 완료 후 삭제했다. 실제 문서 제목 12개 조회는 읽기 전용이다. 원문·질문·문서명·벡터·인증 정보는 Git에 포함하지 않았다.

1. 통제된 후보 재생 56문항으로 후보 8개 제한과 그룹·관련성 선택을 개발했다. 28문항의 사전 지정 calibration 부분에서 무관 질문 최고 점수가 0.243, 본문 정답 최저 점수가 0.564였다. 최소 제외 기준은 무관 점수를 넘는 최소 0.05 간격인 0.25, 낮은 관련성 안내는 정답 최저 점수보다 낮은 0.50으로 고정했다. 제목 조회는 전체 파일명 일치로 보호한다.
2. 모든 범위에서 무조건 후보를 보충한 초안은 다문서 질문에서 정답 문서 포함률이 떨어져 폐기했다. 최종 정책은 5개 이하 문서 범위에만 보충한다. 따라서 초기 56문항의 기존 heldout 표시는 최종 정책의 미관측 검증으로 주장하지 않는다.
3. 최종 정책으로 합성 56문항과 실제 제목 12문항, 총 68문항을 실제 검색 경로에서 비교했다.
4. 이후 정책을 고정한 상태에서 설비명·제목·무관 질문을 바꾼 별도 24문항으로 확인했다. 이 확인 세트의 결과를 보고 기준이나 후보 정책을 다시 조정하지 않았다.

후보가 같으면 두 방식이 같은 Jina 응답을 공유하고 선택 정책만 비교한다. 좁은 범위의 후보가 달라지는 경우 각 후보 집합을 따로 재평가한다. 모든 입력은 기존 본문 prefix 2,400자다. 테스트 도구는 `tools/evaluate_docmind_search_quality.py`, 원문 없는 집계 도구는 `tools/summarize_docmind_search_quality.py`다.

## 한계와 배포 확인

전체 242문서의 실제 업무 질문에 정답을 붙인 평가가 아니다. 제목 조회 1개는 여전히 적중하지 못했고, 유사 주제의 무관 질문 3개는 낮은 관련성 안내와 함께 남는다. 0.25/0.50은 이 모델과 제한된 평가에 맞춘 기준으로 모든 질문의 무오류를 보장하지 않는다. 문서 그룹은 화면 중복을 줄이지만 다른 문서의 유사 본문을 임의 제거하지 않는다.
